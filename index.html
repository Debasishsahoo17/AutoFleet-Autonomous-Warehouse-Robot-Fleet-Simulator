DOCUMENTATION / QUICK START

Welcome to AutoFleet.

AutoFleet simulates a fleet of autonomous mobile robots inside a warehouse. Every tick, agents compete for pick-and-deliver jobs, plan routes using A*, and negotiate safe movement.

▶ Start / Pause

Run the simulation continuously. Speed changes how quickly ticks advance.

⇥ Single-step

Advance one discrete tick while paused to inspect decisions.

⚡ Inject failure

Take a robot offline. Its job returns to the task queue and other robots route around it.

+ Add order

Add a new job, then watch the dispatcher select the closest eligible robot.

▤ Select a robot

Click a robot on the floor map or in the fleet list to see its mission and battery.

↓ Export report

Download a JSON report with per-robot metrics and the full task history.

The safety controller forbids entering occupied cells, preventing vertex collisions and head-on swaps. This is a simulation, not production robot control software.
